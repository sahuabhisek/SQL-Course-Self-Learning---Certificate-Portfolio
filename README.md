Welcome to my SQL repository! Yeh repository un sabhi SQL queries, databases, aur concepts ko showcase karti hai jo maine **Skill Course** (ISO 9001:2015 Certified) ke antargat **Satish Dhwale** sir (Founder & Teacher) ki guidance me sikhaye hain.

## 📋 Course Curriculum & Topics Covered
* **Database Fundamentals:** Relational databases, tables, rows, columns, aur data types ki samajh.
* **DDL & DML Commands:** `CREATE`, `ALTER`, `DROP`, `INSERT`, `UPDATE`, aur `DELETE` statements ka practical implementation.
* **DQL (Data Query Language):** `SELECT` statement ka use karke database se data fetch karna.
* **Filtering & Sorting:** `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, aur `LIMIT` clauses ka upyog.
* **JOINS:** Inner Join, Left Join, Right Join, aur Full Outer Join ke madhyam se multiple tables ko combine karna.
* **Subqueries & Aggregate Functions:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, aur nested queries ka advanced level par use.
